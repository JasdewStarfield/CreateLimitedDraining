<h1 align="center">Create: Limited Draining  <br>
    机械动力：流体抽取限制
    <br><br>
</h1>

<p>A Create addon that allows you to control the biomes to drain certain fluids infinitely.
<p>一个机械动力附属，允许你控制允许某种流体无限抽取的群系。</p>
<br>
<p>By default, it restricts draining infinite lava in the nether only (Controlled by Biome Tag "#createlimiteddraining:infinite_draining_biomes" and Fluid Tag "#createlimiteddraining:infinite_draining_fluids").</p>
<p>默认情况下，它会限制无限抽取岩浆的行为只能在下界进行（使用生物群系标签 "#createlimiteddraining:infinite_draining_biomes" 和流体标签 "#createlimiteddraining:infinite_draining_fluids" 控制）。</p>
<br>
<p>This is my first mod, and it's intended to be used in my own modpack "Path of Truth". I used Copilot for coding guidance. If you encounter any bugs or have any suggestions, please open an issue! Thank you!</p>
<p>这是我的第一个模组，制作的本意是在我的整合包“真理之路”中使用。我在编写的过程中使用了Copilot作为指导。如果你遇到了任何Bug或者有任何建议，请提交Issue！谢谢！</p>
